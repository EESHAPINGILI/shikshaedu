# shikshaedu

In this project,we have extracted real-time data using Python libraries such as
BeautifulSoup and Requests for analysis.
We performed data cleaning and preprocessing using Pandas and
NumPy to ensure data accuracy. We have conducted EDA to identify trends, correlations,
and patterns in datasets.We built visual reports using Matplotlib and Seaborn for insight
generation. We have also applied statistical techniques to support data-driven
conclusions.
